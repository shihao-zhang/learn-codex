# Source Evidence Index

本页是机制级证据索引。`docs/fact-snapshot.md` 记录目标 commit 与路径存在；本页记录“具体机制点”对应的源码证据、核实范围和未解决问题。

## Evidence Levels

- `path-exists`：只证明路径在目标 commit 存在，不证明行为。
- `mechanism-verified`：已读到机制入口、数据结构或控制流，可以支撑章节主映射。
- `behavior-verified`：已读到关键分支、错误路径或状态转换，可以支撑更具体的行为描述。
- `pending`：路径或局部机制存在，但章节语义仍要继续核实。
- `teaching-abstract`：教学整合，不声称是官方架构。

## Convention

本仓使用统一索引，不在每章维护独立 `sources.md`。原因是章节状态、固定 SHA 链接和证据分级需要由 `scripts/check_docs.py` 一次性检查。

每条证据必须包含：章节、机制点、证据级别、固定 SHA 源码链接、已核实范围、未解决问题。除非行内另有说明，本页所有证据的核验日期继承 [fact-snapshot.md](fact-snapshot.md) 的 2026-05-29；Phase 5 新增的 s08 与 s10 证据核验日期为 2026-06-01，目标 commit 不变。证据级别不能自动升级章节状态：章节 README 的状态仍是最终口径。
